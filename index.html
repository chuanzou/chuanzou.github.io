Research

EvolvAttack: Backdooring Self-Evolving VLM Agents
Chuan Zou, Yang Xiang, Zexin Li, Xiaonan Luo, Simin Chen
arXiv preprint, 2026
Self-evolving agents write their own outputs back into memory. We show that a backdoor can stay dormant at deployment and wake up as that memory evolves: near 0.5% attack success at first, over 95% within 100 interactions.
StateHarness: Maintaining Evolving Project State for Long-Horizon Coding Agents
Chuan Zou, Yujun Zhou, Xiaonan Luo, Xiangliang Zhang
arXiv preprint, 2026
A training-free runtime that keeps an explicit project state for coding agents and retrieves the callers, tests and docs each edit affects, raising task completion on three repository-level benchmarks.

Projects

Generative Models for Cloud Removal in Satellite Imagery
Course project at Penn, project lead in a team of three, Spring 2026
A controlled benchmark on 2,000 Sentinel-2 tiles with synthetic clouds at 5–70% coverage, comparing a conditional GAN and mask-guided diffusion against multi-temporal fusion to find where generative fill-in stops being reliable.
